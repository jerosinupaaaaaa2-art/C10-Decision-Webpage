Decision Lab

Compare alternatives under uncertainty. Edit the payoff table, test decision criteria, and follow a transparent staged-filtering process.

1. Payoff Table

Enter payoffs in the same unit (for example, thousands of dollars). State probabilities are percentages and must total 100% for EMV / Bayes.

How the statistics are calculated

Max payoff: the largest payoff for an alternative. Min payoff: its smallest payoff. EMV: each payoff multiplied by its state's probability, then added.

Regret: the best payoff among all original alternatives in a state minus that alternative's payoff. Maximum regret: the largest state regret. Regret benchmarks stay fixed during staged filtering.

All calculations use full precision. Displayed values are rounded to two decimals. Values within 10⁻⁹ are treated as ties.

2. Summary

A quick comparison of each alternative's performance across states of nature.

3. Criterion Decisions

Each criterion compares the complete original set. Different criteria may recommend different alternatives.

4. Staged Filtering

Apply rules in order. Each stage evaluates only the alternatives that survived the previous stage. Choose a criterion and how many top-ranked alternatives to keep. Ties at the cutoff all survive, in their original order. Eliminated alternatives never re-enter.

About this model

This is an educational decision-support model. Maximax is optimistic, Maximin is cautious, Minimax Regret reduces the worst missed opportunity, and EMV / Bayes uses probability-weighted payoffs. No single criterion is automatically correct for every decision; the decision-maker should explain which assumptions fit the situation.
